# 1. 팩토리 메서드 패턴

- 생성(Creational) 패턴
- 각각 다른 객체가 필요한 경우
    - 특정 제품을 생성하는 로직을 캡슐화하고 싶을 때
    - 새로운 제품을 추가할 가능성이 있으며, 객체 생성을 서브클래스로 위임하고 싶을 때
- 객체를 생성하는 인터페이스는 미리 정의하되, 객체 생성은 서브 클래스(팩토리)로 위임하는 패턴
- 객체를 생성해서 반환하는 것 (결과 값이 객체)
- 객체 생성하는 코드를 분리하여 클라이언트 코드와 결합도(의존성)를 낮추어 코드를 건드리는 횟수를 최소화하기 위해
    - 결합도가 낮아지는 이유
        - 다형성을 이용했기 때문
        - 인터페이스를 구현한 객체들은 같은 인터페이스에 상속받았기 때문에 코드에 유연함이 있다
    - 코드를 건드리는 횟수가 최소화되는 이유
        - 객체를 생성하는 코드 부분을 분리시켜 객체의 추가, 수정이 일어나더라도 객체를 생성하는 코드만 건들면 되기 때문
- ex) 노트북, 마우스로 분리

# 2. 추상 팩토리 패턴

- 연관되는 객체들의 조합
    - 여러 개의 연관된 제품을 한 번에 만들어야 할 때
    - 제품군을 교체할 가능성이 있으며, 특정 제품군의 구성을 통째로 바꾸고 싶을 때
- 서로 연관되거나 의존적인 객체들의 조합을 만드는 인터페이스를 제공하는 패턴
- ex) LG, 삼성으로 분리

#### computerFactory

```java
public interface NewComputerFactory {
	public Notebook createNotebook();
	public Mouse createMouse();
}
```


# **팩토리 패턴 vs. 추상 팩토리 패턴 비교**

| **비교 항목** | **팩토리 패턴 (Factory Method)** | **추상 팩토리 패턴 (Abstract Factory)** |
| --- | --- | --- |
| **주요 목적** | 단일 객체(Product) 생성 | 여러 관련 객체(Product Family) 생성 |
| **구현 방식** | 팩토리 메서드를 오버라이딩 | 팩토리 인터페이스에서 여러 객체를 생성 |
| **유연성** | 새로운 제품 추가 시 서브클래스 필요 | 새로운 제품군 추가 시 인터페이스 확장 |
| **적용 예** | 특정 제품의 변형이 필요한 경우 | 같은 테마의 여러 객체를 일관되게 생성해야 할 경우 |
| **예제 제품군** | 하나의 제품 유형(예: ProductA, ProductB) | 여러 제품 유형(예: Chair, Table) |

# 3. 템플릿 메서드

- 행위 패턴
- 알고리즘의 골격은 상위 클래스에 정의하고, 세부 단계는 서브 클래스에서 오버라이드

```java
abstract class ShippingProcess {
    // 템플릿 메서드 - 흐름 고정
    public final void ship() {
        receiveOrder();
        packageItem();      // 포장 방식은 운송 수단마다 다름
        loadVehicle();      // 적재 방식 다름
        deliver();          // 배송 방식 다름
        confirmDelivery();
    }
    
    private void receiveOrder() { /* 공통 */ }
    private void confirmDelivery() { /* 공통 */ }
    
    protected abstract void packageItem();
    protected abstract void loadVehicle();
    protected abstract void deliver();
}

class TruckShipping extends ShippingProcess {
    protected void packageItem() { /* 박스 포장 */ }
    protected void loadVehicle() { /* 트럭 적재 */ }
    protected void deliver() { /* 도로 운송 */ }
}

class ShipShipping extends ShippingProcess {
    protected void packageItem() { /* 컨테이너 포장 */ }
    protected void loadVehicle() { /* 선박 적재 */ }
    protected void deliver() { /* 해상 운송 */ }
}
```

# (과제) 시나리오 구성

M사에서는 2가지 햄버거 세트 메뉴를 가지고 있다. M사의 메뉴 제조 과정을 팩토리 메서드, 추상 팩토리, 템플릿 메서드 디자인 패턴을 적용해서 구현한다. 

- 치킨 버거 세트는 치킨 버거와 치즈 스틱, 사이다로 구성되어 있고, 불고기 버거 세트는 불고기 버거, 감자튀김, 콜라로 구성되어 있다.
- M사에서는 무조건 버거→사이드→음료 순서로 음식을 제조한다.
- 다른 세트나 단품 메뉴는 아직 출시되지 않았다.

## 1. 팩토리 메서드

- 햄버거 세트 만들기
    - 버거 만들기
        - 치킨 버거 만들기
        - 불고기 버거 만들기
    - 사이드 만들기
        - 치즈스틱 만들기
        - 감자튀김 만들기
    - 음료 준비하기
        - 사이다 준비
        - 콜라 준비

## 2. 추상 팩토리

- 햄버거 세트 만들기
    - 치킨 버거 세트 만들기
        - 치킨 버거 만들기
        - 치즈스틱 만들기
        - 사이다 준비
    - 불고기 버거 세트 만들기
        - 불고기 버거 만들기
        - 감자튀김 만들기
        - 콜라 준비

## 3. 템플릿 메서드

- 햄버거 세트 만들기
    - 버거 만들기
    - 사이드 만들기
    - 음료 준비하기
