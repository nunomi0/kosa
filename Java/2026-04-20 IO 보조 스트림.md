- `Date`, `Calendar`는 레거시 → 사용 지양

```java
LocalDate now = LocalDate.now(); // 날짜
LocatTime now2 = LocalTime.now(); // 시간

```

- 날짜 계산

```java

```

- DB 매핑

    - `TIMESTAMP` (DB) = `LocalDateTime` (Java)

## I/O Stream

```java
Stream
├── byte 기반 (바이너리)
│   ├── InputStream  → FileInputStream, BufferedInputStream
│   └── OutputStream → FileOutputStream, BufferedOutputStream
└── char 기반 (텍스트)
    ├── Reader → FileReader, BufferedReader
    └── Writer → FileWriter, BufferedWriter
```

- Buffer가 필요한 이유 → 입출력 누적은 Buffer를 쓰는 게 효율적
    - `FileInputStream`, `FileReader`는 OS 파일 시스템에 직접 접근 → `read()`마다 매번 디스크 접근이라 느림
    - `BufferedXXX`는 내부에 8KB 배열을 두고 동작
        1. 처음 `read()` 호출 시 디스크에서 8KB를 한 번에 버퍼로 가져옴
        2. 이후 `read()`는 메모리 버퍼에서 읽음
        3. 버퍼가 비면 다시 8KB 채움
    - 디스크 접근 횟수가 줄어 성능이 향상
- 자원 닫기는 try-with-resources로

```java
try (BufferedWriter bw = new BufferedWriter(new FileWriter("lotto.txt"))) {
    // 작업
} catch (IOException e) {
    // 처리
}
// 블록 빠져나오면 자동 close
```

- 문자열 누적 → `StringBuilder` 사용
    - String은 불변(immutable)이기 때문에 `+=` 로 이어 붙이면 매번 새 객체가 생성되어 비효율적
    - StringBuilder는 가변(mutable)이라 객체에 계속 추가 가능

```java
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 10000; i++) {
    sb.append(i);  // 같은 객체에 계속 붙임
}
String result = sb.toString();  // 마지막에 한 번만 String으로 변환
```

## I/O 보조 스트림

#### 출력 형식 보조 스트림

1. `printf()`
    - 콘솔 직접 출력
    
    ```java
    System.out.printf("이름: %s, 나이: %d%n", name, age);
    ```
    
2. `String.format()` 
    
    ```java
    String msg = String.format("이름: %s, 나이: %d", name, age);
    System.out.println(msg);
    ```
    
3. `PrintWriter()`
    - (콘솔이 아닌) 파일/스트림에 형식 출력
    - `printf()`, `println()`, `write()` 메서드를 다 갖고 있음
    
    ```java
    PrintWriter writer = new PrintWriter(new FileWriter("result.txt"));
    
    writer.printf("이름: %s, 나이: %d%n", "홍길동", 25);
    writer.println("두 번째 줄");
    writer.write("세 번째 줄\n");
    
    writer.close();
    ```
    

- 폴더 내 파일에서 특정 단어 찾기

```java
public class Ex12_PrintWriter_String_Finder {
	String baseDir = “C:\\Temp”;
	String word = “HELLO”;
	String savetxt = “result.txt”;

	void find() throws IOException{
		File dir = new File(baseDir);
		if (!dir.isDirectory()) {
			System.out.println("유효한 폴더가 아닙니다");
			System.exit(0);
		}
		
		PrintWriter writer = new PrintWriter(new FileWriter(savetxt));
		BufferedReader br = null;
		File[] files = dir.listFiles();
		
		for (int i = 0; i<files.length; i++){
			if (!files[i].isFile()){
				continue;
			}
			br = new BufferedReader(new FileReader(files[i])); // buffer가 혼자 동작 못하니까 FileReader 이용(?)
		
			String line = "";
			while((line=br.readLine()) != null) {
				// read 한 한 문장 안에 특정 단어 포함되어 있는지
				if (line.indexOf(word) != -1) {
					writer.write("word = " + files[i].getAbsolutePath() + "\n";
				}
			}
			writer.flush();
		}
		br.close();
		writer.close();
	}
}
```

#### 객체 직렬화 / 역직렬화

- 직렬화
    - 객체를 분해해서 줄세워 내보내는 과정
    - ex) 탱크를 분해해 부품으로 보내기
- 역직렬화
    - 받아서 다시 조림
    - ex) 부품을 받아 탱크로 복원
- 객체 통신은 `프로세스 ↔ 프로세스`, `파일 ↔ 파일`, `네트워크 ↔ 네트워크` 모두 가능
- 모든 클래스가 직렬화되는 건 아님
    - `Serializable` 인터페이스를 구현해야 가능
- 파일로 직접 내용 확인 불가 → 반드시 역직렬화로만 데이터 확인

- 예제 코드


```java
// 직렬화해서 저장

import java.io.BufferedOutputStream;
import java.io.FileOutputStream;
import java.io.ObjectOutputStream;
import kr.or.kosa.UserInfo;

public class Ex15_ObjectDataOutPutStream {
	public static void main(String[] args) {
	
		String filename = "UserData.txt";

		FileOutputStream  fos = null; // 주 스트림
		BufferedOutputStream bos = null; // 성능 보조 스트림
		ObjectOutputStream out = null;  // 직렬화를 지원하는 보조 스트림
		
		try {
			   fos = new FileOutputStream(filename);
			   bos = new BufferedOutputStream(fos);
			   
			   // 직렬화
			   out = new ObjectOutputStream(bos);
			   
			   // 객체 생성
			   UserInfo u1 = new UserInfo("홍길동", "super", 100);
			   UserInfo u2 = new UserInfo("scott", "tiger", 50);
			   
			   // 직렬화 (줄을 세워서 하나씩 파일에 write)
			   out.writeObject(u2);
			   out.writeObject(u1); 
			   			
		} catch (Exception e) {
			  System.out.println(e.getMessage());
			  
		} finally {
				try {
					  out.close();
					  bos.close();
					  fos.close();
					  System.out.println("파일생성 > buffer > 직렬화 -> write");
				} catch (Exception e2) {
				    System.out.println(e2.toString());
				}
		}
	}
}
```

```java
// 복원 (역직렬화)

import java.io.BufferedInputStream;
import java.io.EOFException;
import java.io.FileInputStream;
import java.io.FileNotFoundException;
import java.io.IOException;
import java.io.ObjectInputStream;

import kr.or.kosa.UserInfo;

public class Ex16_ObjectDataInputStream {

	public static void main(String[] args) {
		
		String filename = "UserData.txt";
		
		FileInputStream fis = null;
		BufferedInputStream bis = null;
		ObjectInputStream in = null;
		
		try {
			fis = new FileInputStream(filename);
			bis = new BufferedInputStream(fis);
			in = new ObjectInputStream(bis); // 역직렬화
			
			Object users = null;
			
			while((users = in.readObject()) != null) {
				System.out.println(((UserInfo)users).toString());
			}
	
		} catch (FileNotFoundException e) {
			System.out.println("파일이 존재하지 않습니다");
		} catch (EOFException e) {
			System.out.println("끝" + e.getMessage());
		} catch (IOException e) {
			System.out.println("파일을 읽을 수 없습니다");
		} catch (ClassNotFoundException e) {
			System.out.println("해당 객체가 존재하지 않습니다");
		} catch (Exception e) {
			System.out.println("나머지 예외");
		}finally {
			try {
				  in.close();
				  bis.close();
				  fis.close();
			} catch (Exception e2) {
				e2.printStackTrace();
			}
		}
	}
}
```

```java
	private void loadFromFile() {  // map 객체 write

	private void saveToFile() {  // map 객체 read

	}
```

### 면접 예상 질문

1. 직렬화를 왜 쓰는가?
    - 객체를 바이트 형태로 변환해서 저장하거나 네트워크로 전송하기 위해 사용
2. `transient`
    - 직렬화 대상에서 제외할 필드에 붙이는 키워드
    - 역직렬화 시 해당 필드는 null/기본값이 됨
3. `serialVersionUID`
    - 직렬화/역직렬화 버전 관리용 식별자
    - 같은 버전끼리만 호환
