# 🎱 Lotto 번호 생성기

콘솔 기반으로 로또 번호를 자동으로 생성하는 프로그램입니다.

---

## ✨ 기능

- 1~45 사이 6자리 로또 번호 생성
- 중복 제거 / 오름차순 정렬
- 가로 연속(차이 1) / 세로 연속(차이 7) 3개 이상 자동 재추첨
- 파일 누적 저장 / 조회

---

## 🧩 클래스 구조

| 클래스 | 책임 |
|---|---|
| `LottoApplication` | 메뉴 흐름, 입력 검증 |
| `LottoMachine` | 번호 생성, 정렬, 연속 패턴 검증 |
| `Lotto` | 번호 데이터, 도메인 상수 |
| `LottoFileRepository` | 파일 읽기 / 쓰기 |

---

## 🤔 고민한 점

### 1. 중복 및 정렬 처리
`Set` 사용 없이 직접 중복, 정렬 알고리즘을 구현해야 하는 조건이 있었습니다.
`boolean[46]`을 flag 맵으로 사용했습니다.

- **중복 검사 O(1)** — 인덱스 접근 한 번으로 즉시 판별
- **정렬 자동화** — 인덱스 순회 시 자연스럽게 오름차순으로 추출, 별도 정렬 함수 불필요
- **메모리 효율** — 46바이트로 6개 숫자의 중복, 정렬을 모두 해결

### 2. `int[]` vs `ArrayList<Integer>`
로또 크기가 6으로 고정되어 동적 확장이 불필요합니다. 따라서
원시 타입을 그대로 저장하는 `int[]`를 선택해 박싱(`int` → `Integer` 변환) 오버헤드를 줄였습니다.

### 3. 상수 위치
`MIN_NUMBER`, `MAX_NUMBER`, `LOTTO_SIZE`는 도메인 의미가 가장 강한 `Lotto` 클래스에 배치해서 응집도를 높였습니다.
