## CRUD 분석

- 데이터베이스 테이블에 변화를 주는 트랜잭션의 CRUD 연산에 대해 CRUD 매트릭스를 작성하여 분석하는 것
    - CRUD: Create / Read / Update / Delete
    - 트랜잭션
        - 데이터베이스의 상태를 변환시키는 하나의 논리적 기능을 수행하기 위한 작업의 단위(논리적 단위)
        - 한꺼번에 모두 수행되어야 할 일련의 연산
        - 데이터 무결성 보장을 위해 ACID 특성을 가짐
            - Atomicity / Consistency / Isolation / Durability
- CRUD 분석으로 테이블에

## CRUD 매트릭스

- 업무 프로세스와 데이터 간 상관 분석표
    - 2차원 형태의 표
        - 행: 프로세스
        - 열: 테이블
        - 행, 열이 만나는 위치: 프로세스가 테이블에 발생시키는 변화를 표시
    - 각 셀에는 보통 C > D > U > R 의 우선순위 적용해서 한 가지 또는 모두 기록
    - OLTP(실시간 데이터 수정 환경) 등에서 사용

## 트랜잭션 분석

- 기능 하나가 실행될 때 DB 작업을 어디부터 어디까지 한 묶음으로 처리할지 정하는 것
    1. 이 기능은 어떤 테이블을 읽고 쓰는가?
    2. 어떤 작업들이 반드시 같이 성공해야 하는가?
    3. 실패하면 어디까지 되돌려야 하는가?
- 업무 개발 담당자가 수행
- 트랜잭션 양을 분석해서 테이블에 저장되는 데이터 양을 유추하고 이를 근거로 DB 용량을 산정하고 구조 최적화
    - 프로세스가 과도하게 접근하는 테이블을 확인 → 여러 디스크에 배치 → 디스크 입출력 분산 → 성능 향상
- 트랜잭션 분석서
    - 포함 내용
        - 트랜잭션명, 실행 조건, 처리 순서, 대상 테이블, CRUD, Commit/Rollback 기준, 예외 상황
    
    | 순서 | 처리 내용 | 대상 테이블 | CRUD | 실패 시 처리 |
    | --- | --- | --- | --- | --- |
    | 1 | 회원 존재 여부 조회 | MEMBER | R | 중단 |
    | 2 | 상품 상태 조회 | PRODUCT | R | 중단 |
    | 3 | 재고 수량 조회 | STOCK | R | 중단 |
    | 4 | 주문 생성 | ORDERS | C | Rollback |
    | 5 | 주문상세 생성 | ORDER_ITEM | C | Rollback |
    | 6 | 결제 생성 | PAYMENT | C | Rollback |
    | 7 | 재고 차감 | STOCK | U | Rollback |
    | 8 | 전체 성공 | COMMIT |  | 저장 |
    | 9 | 중간 실패 | ROLLBACK |  | 취소 |
